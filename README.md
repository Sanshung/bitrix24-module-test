ТЕСТОВОЕ ЗАДАНИЕ ПО Битрикс 24 Коробочная
В CRM сущности  "сделка" есть штатное поле поле CONTACT_ID., в котором хранится ID сущности "контакт". То есть эти сущности связанны.
Создать свой модуль для Коробочной версии Битрикс 24. Он должен корректно устанавливаться и удаляться штатными средствами. 
В модуле создать контроллер, реализующий свой REST метод, расширяющий штатный REST API Битрикс 24. Метод должен быть доступен для создания вебхуков.


Метод должен возвращать данные из сущности сделок и связанных с ними контактов.
То есть, позволять получать все поля сущности сделка и все поля сущности контакт(включая пользовательские).
Требования:
1) Должна быть возможность фильтрации по любому полю этих сущностей (аналогично фильтру ORM ).
2) Должна быть возможность сортировки по любому из полей(аналогично сортировке ORM)
3) Должна быть предусмотрена возможность указание числа получаемых элементов и сдвига(limit,offset  ORM) 
4) Должен быть предохранитель, от получения больше 100 элементов за раз, чтоб не перегрузить систему случайно.
5) Должно быть подсчитано общее число элементов, соответствующих условиям фильтрации.
6) Должно быть возвращено  какой следующий сдвиг(offset) нужно передать, чтоб получить элементы находящееся далее. Если дальше элементов нету то null.
Примечания: 
1.)берём только поля сущностей "Контакт" и "Сделка", не усложняем (multifield -отдельные сущности в которых хранятся телефоны, email и тд. не берём)
2) Поля типа "список" возвращаем как есть (Числовой ID), не усложняем(преобразовывать в xml ид не надо).
3) Когда добавите REST метод в модуль, чтобы он отобразился во "входящие вебхуки" нужно очистить кэш.
